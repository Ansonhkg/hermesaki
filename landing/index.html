SELF-HOSTING, WITH THE DETAILS INCLUDED

Your mail deserves a home.

Hermesaki brings the pieces together. You provide the server and domain, and remain responsible for running them.

Mail stays with you.

Messages and attachments live in Stalwart. Hermesaki adds the API, mailbox credentials, send queue and operator dashboard.

Access is explicit.

Separate mailbox keys from operator access. Choose permissions, set expiry and revoke an agent’s key when its work is done.

Configuration in context.

Review supported DNS, tunnel and access-policy changes before applying them. Keep your webmail address alongside your server settings.
