Our first measured setup.

12 September 2026 · One agent-assisted application reinstall. A baseline for improvement, not a speed promise.

58m 16s from installer start to full verification. 1h 09m 34s including teardown and cleanup.

Native Codex MCP sent, read and replied to real email. Gmail receipt was independently confirmed. SPF, DKIM and DMARC passed, and all 11 required setup checks passed.

Waits overlapped useful work

  • Owner approval window: 6m 36s. Two questions were resolved in one response. The shorter firewall approval window was inside the credential approval window. This is not measured hands-on user time.
  • Gmail DKIM failure to passing email: about 30m 16s. Consistent with negative DNS caching. MCP, webmail and security verification continued during that span. No signing-key or source change was needed.
  • Local DNS repair: about 7 minutes. Also overlapped verification. The subagent lost browser access, and a supervisor handled browser operations; that assistance was not separately timed as overhead.

Subtracting the DNS span from the total would not produce a valid “setup excluding DNS” result. Pure DNS idle time, individual screenshot effort and agent/tool overhead were not separately measured.

What the measurement includes

The timer ran from 20:40:49 to 21:50:23 UTC. The installer started at 20:48:55 and completed at 21:47:11. Native MCP was demonstrably usable approximately 44m 05s after installer start.

Preparation and provider logins were outside this timer. One recorded login request took 2m 09s to observed resolution; earlier preparation was not fully timed. An evidence-packaging checkpoint followed cleanup by another 3m 16s. Later reporting is excluded.

This was a clean application reinstall on an existing Linux VPS with OS packages, Docker cache, provider accounts and signed-in sessions retained. A pinned private prerelease archive was supplied. It was not an unassisted agent, blank-OS or public-clone test. Source code remained unchanged during the rehearsal.

We retained 39 actual screenshots and timestamped private logs. This page is a sanitized summary: it does not publish mailbox content, credentials, account identifiers or private infrastructure. Initial test messages reached Spam; successful delivery does not guarantee Inbox placement.

Help bring setup under 10 minutes

The target is configuration in under 10 minutes once required inputs, credentials, access and approvals are ready. DNS waiting must be shown separately, with a supported estimate and a way to resume. Fully verified status still requires real delivery, authentication and permission checks.
