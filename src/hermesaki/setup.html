          Check your installation
          Services can be running while delivery or access checks are still pending. Setup will remain incomplete until every required check is verified.
            Check public mail delivery ports
            Run the downloaded challenge on a separate publicly addressed machine with Hermesaki installed: python -m hermesaki.setup_network < challenge.json > result.json. This makes a connection and sends no mail. Keep the challenge private.
            Check external email
            Send one verification email to an external inbox you control. Reply to it, then download the original received test message from that provider. Hermesaki checks the provider’s SPF, DKIM and DMARC report and the matching reply. The uploaded original is not retained.
            Check agent access
            Use a Cloudflare Access service token authorized for the operator hostname. This checks mailbox read access and permission denials. It sends no email. Credentials are used for this check only.
            Save your mailbox and operator credentials before finishing. Setup changes will close after verification succeeds.
            Agent setup uses the same API: /v1/setup. This setup service listens only on this machine.
